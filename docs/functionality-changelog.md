## 后续记录方式

后续功能变化在同一工作单元更新[当前功能说明](current-functionality.md)对应章节，并在本日志末尾的日期记录区追加条目。每项写明发生日期和实际行为变化，需要时说明旧规则的替代关系；能引用已存在提交时附固定链接，与实现一同提交的新条目可通过本文件 Git 历史定位，避免为填入自身提交号反复提交。

本文件持续保留同一个起点，已经写回现行说明的历史条目也不删除。计划与待办不记为完成，验证说明只记录实际完成的检查，生产部署与远端设备验收需要各自证据；Git 提交仍保留简短说明，不再按每次更新新建其他专题日志。
