功能变化在同一工作单元更新[当前功能说明](current-functionality.md)，并在上方日期记录区追加小节。标题先说明用户能感知的变化，正文用简短段落或少量要点解释，必要时另行注明后续调整。

- **保留追溯依据。** 记录发生日期，能引用已存在提交时附固定链接；与实现一同提交的新条目可通过本文件的 Git 历史定位。日志始终从 `5714334` 开始，写回现行说明后的历史条目继续保留。
- **区分完成与计划。** 未完成事项留在需求表，验证只记录实际完成的检查。生产部署和远端设备验收各自需要证据，后续不再按每次更新新建其他专题日志。
